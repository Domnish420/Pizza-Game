# The sound kit

Every sound in the game is generated by `make_sfx.py` from sine waves and shaped noise (numpy only), the way the
models are built by `tools/models/`. Rebuild after a change, then check the sheet:

```
python3 tools/sfx/make_sfx.py            # all of them (or name some: make_sfx.py bell cut)
python3 tools/sfx/sheet.py /tmp/sfx.png  # a spectrogram and waveform of each; exits 1 on clipping, DC or a loop seam
```

The files land in `assets/sfx/<name>.wav` (mono, 16-bit, 22.05 kHz, about 1.3 MB in all). The game plays a one-shot
with `Art.sfx(name, vary, gap)` (vary nudges the pitch each time; gap is the least time between two plays) and a
background loop with `Art.loop(name, level)`, called every frame with how loud it should be. A hand-made `.wav` with
the same name replaces a generated one. `tests/test_sound.gd` checks that every sound the code asks for exists.

The style is a toy kitchen: soft, warm, short, never harsh, nothing louder than about -6 dB.

| Sound | When |
| --- | --- |
| `tap` | Buttons and things you touch |
| `ding` | A new order on the rail |
| `bell` | The pass bell: a pizza going out |
| `cash` | The till: a customer paying, an order paid for |
| `bad` | Something went wrong: walked out, burnt, refused |
| `up` | Something done well: a guide step, a good day |
| `punch` | The clock: clocking in and out |
| `ticket` | Taking a ticket off the rail |
| `slap` | Pressing and stretching the dough |
| `scoop`, `plop` | The ladle dipping into the sauce, and the sauce landing |
| `sprinkle` | Cheese and toppings going on |
| `peel` | The peel sliding a pizza in or out of the oven |
| `cut` | The pizza wheel |
| `log` | A log thrown on the fire |
| `ring` | The phone (an order to take) |
| `knock` | A delivery at the back door |
| `app` | An order from the delivery app |
| `fire` (loop) | A lit wood oven: louder at the oven, and softly on the title screen |
| `murmur` (loop) | The customers in the dining room or at the hatch: louder when you face them |
| `room` (loop) | The kitchen's extractor hum, always there in the kitchen |
